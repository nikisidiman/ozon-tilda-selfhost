# Доставка Ozon для Tilda

Бесплатная интеграция для интернет-магазина на Tilda: покупатель прямо в корзине выбирает пункт выдачи Ozon и видит цену доставки, а после заказа отправление само появляется в вашем кабинете Ozon Доставки.

Работает на **вашем** сервере: никаких посредников, абонентской платы за сервис и чужого доступа к вашим ключам Ozon и заказам. Вы платите только за сервер (обычно 300–700 ₽ в месяц) и за доставку по своему договору с Ozon.

## Как поставить, если вы не программист

Проще всего — с ИИ-агентом (Claude Code, Codex, Cursor и подобные). Откройте агента на своём компьютере и напишите ему:

> Поставь мне интеграцию «Доставка Ozon для Tilda» по инструкции из этого репозитория: https://github.com/nikisidiman/ozon-tilda-selfhost — веди меня по шагам.

Агент прочитает инструкцию [AGENTS.md](AGENTS.md) и проведёт по всему пути: поможет выбрать и арендовать сервер, подключиться к нему, установит программу, настроит адрес с HTTPS, ключи Ozon и корзину Tilda. Вам останется нажимать кнопки в панелях хостинга, Tilda и Ozon — агент скажет, какие. Это займёт около часа, большая часть — ожидание.

## Что понадобится

| Что | Зачем | Где взять |
|---|---|---|
| Магазин на Tilda с корзиной | сюда встраивается выбор пункта выдачи | ваш сайт; нужен тариф, где можно вставлять свой код в HEAD (Personal или Business) |
| Доступ к настройкам домена (DNS) | создать адрес вида `delivery.ваш-магазин.ru` для сервера | там, где куплен домен: REG.RU, RU-CENTER, Timeweb, Beget и т. п. |
| Кабинет Ozon Доставки для бизнеса | ключи, по которым считается цена и создаются отправления | [dostavka.ozon.ru](https://dostavka.ozon.ru/) → «Для бизнеса» → «Подключить». Кабинет продавца seller.ozon.ru **не подходит** |
| Телефон, к которому привязан аккаунт Ozon | без него Ozon не считает цену | ваш номер |
| Сервер (VPS) | здесь работает программа | любой хостинг: Ubuntu 24.04, 1 процессор, 2 ГБ памяти, 20 ГБ диска |

Без ключей Ozon программа тоже запускается — в тестовом режиме с условными ценами. Можно сначала всё проверить, а ключи вставить потом.

## Как это работает

1. Вы вставляете одну строку кода в настройки сайта Tilda.
2. Покупатель выбирает в корзине доставку «Озон» — появляется список пунктов выдачи его города и цена от Ozon по вашему договору. Можно добавить наценку или бесплатную доставку от суммы заказа.
3. Корзина проверяет, что на телефон покупателя есть аккаунт Ozon (без него Ozon не выдаст заказ).
4. После оплаты Tilda присылает заказ на ваш сервер, и он создаёт отправление в кабинете Ozon Доставки. Вам остаётся упаковать посылку и сдать её в пункт приёма.

## Установка вручную (для тех, кто умеет работать с сервером)

На чистом сервере Ubuntu 22.04 / 24.04:

```bash
curl -fsSL https://raw.githubusercontent.com/nikisidiman/ozon-tilda-selfhost/main/install.sh | sudo bash
sudo ozon-tilda setup
```

Перед `setup` создайте в DNS A-запись поддомена (например, `delivery.shop.ru`) на IP сервера и убедитесь, что у сервера открыты входящие порты 80 и 443. Мастер `setup` спросит адрес, получит HTTPS-сертификат, примет ключи Ozon и по шагам объяснит, что нажать в Tilda.

## Команды на сервере

| Команда | Что делает |
|---|---|
| `sudo ozon-tilda setup` | Мастер настройки. При повторном запуске показывает, что уже сделано, и даёт пройти только нужные шаги, например `sudo ozon-tilda setup 8 9`. Enter в любом вопросе оставляет текущее значение. |
| `sudo ozon-tilda show` | Текущие настройки и код для Tilda |
| `sudo ozon-tilda check` | Проверить ключи Ozon и сделать пробный расчёт |
| `sudo ozon-tilda logs` | Заказы, пришедшие от Tilda, и созданные отправления. `logs <номер заказа>` — что именно прислала Tilda (данные покупателя скрыты, записи хранятся 30 дней) |
| `sudo ozon-tilda update` | Скачать новую версию и пересобрать. Настройки, база и сертификаты сохраняются |
| `sudo ozon-tilda restart` | Перезапустить |

### Шаги мастера

1. **Адрес сервера** — поддомен, HTTPS-сертификат сервис получит сам.
2. **Сайт на Tilda** — домен магазина.
3. **Код в HEAD** — строка для «Настройки сайта → Вставка кода».
4. **Доставка в корзине** — продвинутый режим вариантов доставки и «Своя доставка по адресу» со словом «Озон».
5. **Ключи Ozon Доставки** — Client ID, Client Secret и телефон.
6. **Заказы в Ozon и вебхук** — создавать ли отправления и как подключить вебхук к корзине.
7. **Город отгрузки** — откуда вы отправляете посылки.
8. **Расчёт цены** — типовая коробка, вес посылки, порог бесплатной доставки, наценка.
9. **Значок Озон** рядом с названием доставки.
10. **Публикация и проверка** — мастер проверит, что код появился на сайте, и сделает пробный расчёт.

## Ключи Ozon Доставки

1. Зарегистрируйтесь в [Ozon Доставке для бизнеса](https://dostavka.ozon.ru/): «Для бизнеса» → «Подключить». Примите оферту в кабинете и дождитесь одобрения.
2. В кабинете: **API интеграции → Управление частными приложениями → «Создать»**.
3. Отметьте **«Все методы Delivery API»** и нажмите «Создать». Если хотите выдать минимум прав — отметьте методы для пунктов выдачи, проверки доступности доставки, подбора пункта отгрузки, настройки методов доставки и оформления заказа (и «Методы для работы с отправлениями», если отправления нужно сразу подтверждать).
4. В строке приложения нажмите значок ключа и скопируйте Client ID и Client Secret.

Ключи вводятся только на вашем сервере (`sudo ozon-tilda setup 5`) и хранятся там же. Никому их не пересылайте.

## Где что лежит на сервере

- `/opt/ozon-tilda` — программа (git-репозиторий: видно, если что-то правили).
- `/opt/ozon-tilda/.env` — ключи и пароли. Секретный файл.
- `/opt/ozon-tilda/pgdata` — база данных (настройки магазина, справочник пунктов, журнал заказов).
- `/opt/ozon-tilda/caddy` — HTTPS-сертификаты.

Три контейнера Docker: `ozon-tilda-app` (программа), `ozon-tilda-db` (база Postgres), `ozon-tilda-caddy` (HTTPS). Журнал программы: `sudo docker logs ozon-tilda-app --tail 100`.

**Заказ не появился в Ozon?** Начните с `sudo ozon-tilda logs`. Если записей нет совсем — Tilda не отправляет заказы: проверьте вебхук в «Настройки сайта → Формы» и что он отмечен в блоке корзины. Если запись есть — в ней написано, почему отправление не создано.

## Данные покупателей

Программа не хранит персональные данные покупателей дольше, чем нужно: телефоны — только в виде хэша для кеша проверки, в журнале вебхуков имена, телефоны и адреса скрыты, записи удаляются через 30 дней, IP-адреса в журнале обрезаны. Данные покупателя (имя, телефон) передаются в Ozon только для создания отправления. Обработчик персональных данных в этой схеме — вы сами, как владелец магазина; упомяните передачу данных в Ozon в политике конфиденциальности сайта.
